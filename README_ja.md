# AIプロンプトオプティマイザー

📖 **新機能: 英語ドキュメント利用可能！** ナビゲーションバーの「Documentation」ボタンをクリックして、包括的な英語のユーザーガイド、チュートリアル、機能説明にアクセスしてください。

Deepseek-V3を搭載したプロンプト最適化ツール。有料サブスクリプションモデルをサポートし、ユーザーがAIプロンプトを改善・洗練させ、AI対話の効果と品質を向上させるのを支援します。

## ✨ 機能

- 🧠 **Deepseek-V3駆動** - 先進的なDeepseek-V3モデルを使用してプロンプトを分析・改善
- 🔐 **ユーザー認証システム** - Supabaseベースの安全なログイン・登録機能
- 💳 **有料サブスクリプションモデル** - Stripe決済統合、個人版とプロ版のサブスクリプションをサポート
- 📊 **使用回数管理** - サブスクリプションプランに基づいて最適化回数を管理
- ❤️ **お気に入り管理** - 満足のいく最適化結果をお気に入りに保存し、いつでも閲覧・管理
- 🎯 **多様な最適化戦略** - 包括的最適化、明確性向上、具体性強化、創造性促進など複数の戦略を提供
- 🧮 **強化された推論能力** - Deepseek-V3の強力な推論能力を活用した深い最適化
- 📊 **詳細な分析レポート** - 明確性、具体性、有効性などの次元でのスコアと分析を提供
- 💰 **カスタマーポータル** - Stripeカスタマーポータル統合、ユーザーはサブスクリプションと請求書を自己管理可能
- 🎨 **モダンなインターフェース** - 美しく使いやすいReactフロントエンド
- ⚡ **リアルタイム最適化** - 迅速な応答、即座に最適化結果を取得
- 📝 **多様な提案** - 複数の代替最適化案を提供
- 📱 **レスポンシブデザイン** - デスクトップとモバイルに対応
- 🔒 **安全な決済** - Stripeを使用した安全な決済、複数の支払い方法をサポート

## 🚀 クイックスタート

### 環境要件

- Node.js 16.x 以上
- npm または yarn
- Deepseek API Key (AI機能用)
- Supabaseプロジェクト (ユーザー認証用)
- Stripeアカウント (決済機能用)

### インストール手順

1. **プロジェクトのクローン**
   ```bash
   git clone <repository-url>
   cd prompt-optimizer
   ```

2. **依存関係のインストール**
   ```bash
   npm install
   ```

3. **環境設定**
   ```bash
   cp env.example .env
   ```
   
   `.env` ファイルを編集し、必要な設定を追加：
   ```
   PORT=3001
   
   # AI機能設定
   DEEPSEEK_API_KEY=your_deepseek_api_key_here          # 必須、AI機能用
   
   # ユーザー認証設定
   VITE_SUPABASE_URL=your_supabase_project_url          # 必須、ユーザー認証用
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key        # 必須、ユーザー認証用
   
   # 決済機能設定
   VITE_STRIPE_PUBLISHABLE_KEY=pk_test_your_key         # 必須、Stripe公開可能キー
   STRIPE_SECRET_KEY=sk_test_your_key                   # 必須、Stripeシークレットキー
   STRIPE_WEBHOOK_SECRET=whsec_your_webhook_secret      # 必須、Webhook検証用
   ```

4. **外部サービスの設定**
   
   - **Deepseek API**: [Deepseek設定ガイド](./DEEPSEEK_SETUP.md)を参照
   - **Supabase**: [Supabase設定ガイド](./SUPABASE_SETUP.md)を参照
   - **Stripe決済**: [Stripe設定ガイド](./STRIPE_SETUP.md)を参照

5. **バックエンドサービスの起動**
   ```bash
   npm run server
   ```

6. **フロントエンド開発サーバーの起動**
   ```bash
   npm run dev
   ```

7. **アプリケーションへのアクセス**
   
   ブラウザで `http://localhost:3000` にアクセス

## 🎯 使用ガイド

### ユーザー登録とサブスクリプション

1. **アカウント登録** - 「Login」ボタンをクリックし、「今すぐ登録」を選択
2. **メールアドレス確認** - メールアドレスを確認（必要な場合）
3. **サブスクリプションプランの選択** - 価格ページで適切なサブスクリプションプランを選択
4. **支払い完了** - Stripeで安全に支払い、クレジットカードとPayPalをサポート
5. **利用開始** - 支払い成功後、最適化サービスの利用を開始

### サブスクリプション管理

- **サブスクリプション状態の確認** - 価格ページで現在のサブスクリプション情報を確認
- **サブスクリプション管理** - 「サブスクリプション管理」をクリックしてStripeカスタマーポータルに移動
- **プラン変更** - カスタマーポータルでサブスクリプションプランをアップグレードまたはダウングレード
- **サブスクリプションキャンセル** - いつでもキャンセル可能、サブスクリプション期間終了まで引き続きサービスを利用可能
- **請求書ダウンロード** - カスタマーポータルで支払い請求書をダウンロード

### 基本的な使用フロー

1. **アカウントにログイン** - 登録したメールアドレスとパスワードでログイン
2. **サブスクリプション状態の確認** - アクティブなサブスクリプションプランがあることを確認
3. **元のプロンプトを入力** - 左側のテキストボックスに最適化したいプロンプトを入力
4. **最適化戦略の選択** - ニーズに応じて適切な最適化戦略を選択：
   - **包括的最適化**：プロンプトのすべての側面を総合的に改善、Deepseek-V3の推論能力を活用
   - **明確性向上**：プロンプトの明確性と理解しやすさを向上
   - **具体性強化**：プロンプトの具体性と精度を向上
   - **創造性促進**：より創造的な回答を引き出すようプロンプトを最適化
5. **最適化開始** - 「最適化開始」ボタンをクリックまたはショートカットキー Ctrl/Cmd + Enter を使用
6. **結果の確認** - 右側で最適化されたプロンプトと詳細な分析レポートを確認
7. **最適化結果をお気に入りに保存** - お気に入りボタンをクリックして満足のいく最適化結果を個人のお気に入りに保存
8. **コピーして使用** - コピーボタンをクリックして最適化されたプロンプトをクリップボードにコピー

### 使用回数管理

- **残り回数の確認** - インターフェースで今月の残り最適化回数をリアルタイムで表示
- **回数が尽きた場合の対処** - 月の回数が尽きた場合、サブスクリプションプランをアップグレードするか、翌月のリセットを待つ
- **アップグレード通知** - システムは使用制限に近づくとアップグレードを検討するよう通知

### お気に入り管理機能

#### 最適化結果のお気に入り登録
- 最適化結果ページで「お気に入り」ボタンをクリック
- 後で見つけやすいようにカスタムタイトルを追加
- システムは元のプロンプト、最適化結果、戦略、スコアを含む完全な最適化情報を保存

#### 個人お気に入りの管理
- ナビゲーションバーの「お気に入り」タブをクリックしてお気に入り管理ページに移動
- **検索機能**：タイトルまたはコンテンツでお気に入りを検索
- **フィルター機能**：最適化戦略でお気に入りリストをフィルター
- **並べ替え機能**：時間、タイトル、または戦略で並べ替え
- **タイトル編集**：ダブルクリックまたは編集ボタンをクリックしてお気に入りのタイトルを変更
- **コンテンツのコピー**：お気に入りの最適化されたプロンプトをワンクリックでコピー
- **お気に入りの削除**：不要なお気に入りアイテムを削除

#### お気に入りデータのセキュリティ
- すべてのお気に入りデータはSupabaseクラウドに保存
- ユーザーレベルのデータ分離と安全なアクセスをサポート
- 自動バックアップ、データは決して失われない

## 🔧 API インターフェース

### プロンプト最適化
```http
POST /api/optimize
Content-Type: application/json

{
  "prompt": "最適化するプロンプト",
  "strategy": "comprehensive"
}
```

### 決済関連インターフェース

#### 決済セッションの作成
```http
POST /api/create-checkout-session
Content-Type: application/json

{
  "priceId": "price_xxxxx",
  "userId": "user_id",
  "successUrl": "https://domain.com/payment-success",
  "cancelUrl": "https://domain.com/pricing"
}
```

#### サブスクリプション情報の取得
```http
GET /api/subscription/:userId
```

#### カスタマーポータルセッションの作成
