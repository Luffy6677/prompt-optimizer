# AI プロンプト最適化ツール

Deepseek-V3をベースとしたプロンプト最適化ツール。ユーザーのAIプロンプトを改善・洗練し、AI対話の効果と品質を向上させます。

## ✨ 特徴

- 🧠 **Deepseek-V3駆動** - 先進的なDeepseek-V3モデルを使用してプロンプトを分析・改善
- 🔐 **ユーザー認証システム** - Supabaseベースの安全なログイン・登録機能
- ❤️ **お気に入り管理** - 満足のいく最適化結果をお気に入りに保存し、いつでも閲覧・管理
- 🎯 **多様な最適化戦略** - 包括的最適化、明確性向上、具体性強化、創造性刺激など多様な戦略を提供
- 🧮 **強化された推論能力** - Deepseek-V3の強力な推論能力を活用した深層最適化
- 📊 **詳細な分析レポート** - 明確性、具体性、有効性などの次元でのスコアリングと分析
- 🎨 **モダンなインターフェース** - 美しく使いやすいReactフロントエンド
- ⚡ **リアルタイム最適化** - 迅速なレスポンスで即座に最適化結果を取得
- 📝 **多様な提案** - 複数の代替最適化案を提供
- 📱 **レスポンシブデザイン** - デスクトップとモバイルに対応

## 🚀 クイックスタート

### 環境要件

- Node.js 16.x 以上
- npm または yarn
- Deepseek API Key (AI機能用)
- Supabaseプロジェクト (ユーザー認証用、オプション)

### インストール手順

1. **プロジェクトのクローン**
   ```bash
   git clone <repository-url>
   cd prompt-optimizer
   ```

2. **依存関係のインストール**
   ```bash
   npm install
   ```

3. **環境設定**
   ```bash
   cp env.example .env
   ```
   
   `.env` ファイルを編集し、必要な設定を追加：
   ```
   PORT=3001
   DEEPSEEK_API_KEY=your_deepseek_api_key_here          # 必須、AI機能用
   VITE_SUPABASE_URL=your_supabase_project_url          # オプション、ユーザー認証用
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key        # オプション、ユーザー認証用
   ```
   
   **注意**：Supabaseを設定しない場合でもアプリは動作しますが、ユーザー認証機能は無効になります。

4. **Supabaseの設定（オプション）**
   
   ユーザー認証機能を有効にする場合は、[Supabase設定ガイド](./SUPABASE_SETUP.md) を参照して詳細な設定を行ってください。

5. **バックエンドサービスの起動**
   ```bash
   npm run server
   ```

6. **フロントエンド開発サーバーの起動**
   ```bash
   npm run dev
   ```

7. **アプリケーションへのアクセス**
   
   ブラウザで `http://localhost:3000` にアクセス

## 🎯 使用ガイド

### ユーザー認証（オプション機能）

Supabaseを設定した場合、アプリはユーザー認証機能を提供します：

1. **アカウント登録** - 「Login」ボタンをクリックし、「今すぐ登録」を選択
2. **メール確認** - Supabaseの設定により、メール確認が必要な場合があります
3. **ログイン** - 登録したメールアドレスとパスワードでログイン
4. **ログアウト** - ユーザーアバターをクリックし、「ログアウト」を選択

**注意**：Supabaseを設定していない場合、アプリは自動的に認証機能を無効にし、すべてのユーザーが直接最適化機能を使用できます。

### 基本的な使用フロー

1. **アカウントにログイン** - 認証機能が有効な場合は先にログイン（無効の場合はこのステップをスキップ）
2. **元のプロンプトを入力** - 左側のテキストボックスに最適化したいプロンプトを入力
3. **最適化戦略を選択** - ニーズに応じて適切な最適化戦略を選択：
   - **包括的最適化**：プロンプトの各側面を全面的に改善し、Deepseek-V3の推論能力を活用
   - **明確性向上**：プロンプトの明確性と理解しやすさを向上
   - **具体性強化**：プロンプトの具体性と精度を向上
   - **創造性刺激**：より創造的な回答を引き出すようにプロンプトを最適化
4. **最適化開始** - 「最適化開始」ボタンをクリックまたはショートカットキー Ctrl/Cmd + Enter を使用
5. **結果を確認** - 右側で最適化されたプロンプトと詳細な分析レポートを確認
6. **最適化結果をお気に入りに追加** - お気に入りボタンをクリックして満足のいく最適化結果を個人のお気に入りに保存
7. **コピーして使用** - コピーボタンをクリックして最適化されたプロンプトをクリップボードにコピー

### お気に入り管理機能

#### 最適化結果のお気に入り追加
- 最適化結果ページで「お気に入り」ボタンをクリック
- お気に入りにカスタムタイトルを追加して、後で見つけやすくする
- システムは元のプロンプト、最適化結果、戦略、スコアを含む完全な最適化情報を保存

#### 個人のお気に入り管理
- ナビゲーションバーの「お気に入り」タブをクリックしてお気に入り管理ページに移動
- **検索機能**：タイトルまたは内容でお気に入りを検索
- **フィルター機能**：最適化戦略でお気に入りリストをフィルター
- **ソート機能**：時間、タイトル、または戦略でソート
- **タイトル編集**：ダブルクリックまたは編集ボタンをクリックしてお気に入りのタイトルを変更
- **内容コピー**：ワンクリックでお気に入りの最適化されたプロンプトをコピー
- **お気に入り削除**：不要なお気に入り項目を削除

#### お気に入りデータのセキュリティ
- すべてのお気に入りデータはSupabaseクラウドに保存
- ユーザーレベルのデータ分離と安全なアクセスをサポート
- 自動バックアップ、データは永久に失われません

## 🛠️ 技術アーキテクチャ

### フロントエンド技術スタック
- **React 18** - ユーザーインターフェースフレームワーク
- **Vite** - 高速なフロントエンドビルドツール
- **Tailwind CSS** - アトミックCSSフレームワーク

- **Axios** - HTTPクライアント

- **Node.js** - ランタイム環境
- **Express** - Webフレームワーク
